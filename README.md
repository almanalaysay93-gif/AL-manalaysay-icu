# AL Manalaysay ICU — Drip Rate Calculator

A comprehensive ICU drip rate calculator for bedside clinical use. Computes infusion rates for 16+ critical care drugs based on SPMC (Southern Philippines Medical Center) protocols.

## Features

- **16+ ICU Drugs**: Dopamine, Dobutamine, Levophed, Epinephrine, NTG, Cordarone, Heparin, and more
- **Multiple Container Options**: 50cc Syringe Pump, 100cc Soluset, 250cc IVF Bag
- **Bidirectional Calculation**: Dose → Rate and Rate → Dose
- **Electrolyte Deficit Calculators**: K⁺, Na⁺, NaHCO₃ replacement
- **Custom Drip Calculator**: Enter any drug amount, volume, and dosing unit
- **Handheld Clinical Math Calculator**: Quick arithmetic at the bedside
- **Hospital-Specific Protocols**: Levophed concentrations configured for local hospital standards

## How to Use

Open `index.html` in any web browser — no installation required.

## Tech Stack

- HTML, CSS, JavaScript (vanilla — no frameworks)
- Runs entirely in the browser, no server needed
